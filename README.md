# 🖥️ EDT-Pages 可视化控制面板

本项目是 [edgetunnel](https://github.com/cmliu/edgetunnel) 边缘计算代理项目的高级静态前端页面（UI 控制面板）。配合 `edgetunnel` 后端的 Cloudflare Worker 使用，为您带来极具现代感、操作流畅的可视化节点管理体验。

## ✨ 核心特性

- **纯静态架构**：完全由 HTML/JS/CSS 构建，安全性极高，不存储任何隐私数据。
- **配置云端同步**：通过后端的强鉴权 API，直接将配置热重载写入 Cloudflare KV 数据库。
- **自定义 VPS 节点编排**：独创的可视化管理界面，支持录入直连、小黄云 CDN 代理与 Argo 隧道中转等多种节点。
- **智能节点测速与组装**：结合 Cloudflare Anycast 优选 IP，自动帮您生成上百个低延迟高质量的订阅节点。
- **完全解耦**：前后端分离架构，支持您将此前台页面一键私有化部署。

## 🚀 Cloudflare Pages 详细部署教程（极速拉起）

因为本项目是纯静态前端代码，部署到 Cloudflare Pages 非常简单，**无需任何构建命令，也无需配置任何环境变量！**

### 步骤 1：Fork 本仓库
点击本页面右上角的 **Fork** 按钮，将本项目复制到您自己的 GitHub 账号下。如果您觉得好用，别忘了顺手点个 **Star 🌟**！

### 步骤 2：连接到 Cloudflare Pages
1. 登录您的 [Cloudflare 控制台](https://dash.cloudflare.com/)。
2. 在左侧菜单找到 **「Workers 和 Pages」**。
3. 点击右侧蓝色的 **「创建应用程序」** 按钮，然后选择 **「Pages」** 选项卡。
4. 点击 **「连接到 Git」**，授权您的 GitHub 账号。
5. 在存储库列表中，勾选您刚刚 Fork 的 `EDT-Pages.github.io`（或您自定义的名字），点击 **「开始设置」**。

### 步骤 3：极简部署
在“设置构建和部署”页面中：
- **项目名称**：您可以随意起个名字（这决定了您分配到的免费二级域名）。
- **生产分支**：默认 `main` 即可。
- **框架预设**：保持默认的 `None`。
- **构建命令**：**留空**（什么都不要填）。
- **构建输出目录**：**留空**（什么都不要填）。
- **环境变量**：**不需要配置任何变量**。

直接点击最下方的 **「保存并部署」**！

### 步骤 4：获取您的前端域名并绑定后端
1. 等待几秒钟部署完成后，系统会分配给您一个专属链接（例如：`https://my-ui-panel.pages.dev`）。
2. 去您的**后端项目 (`edgetunnel`)** 的设置中，添加一个环境变量 `PAGES_URL`，值为您刚才获得的链接。
3. 以后直接访问您后端的 `/admin` 路径，系统就会自动加载这个漂亮的前端面板了！

## 🔒 安全与防坑注意事项

> [!IMPORTANT]
> **数据安全性**
> 本项目的前端页面是一个“空壳”。所有的隐私配置、节点链接和密码，全部存放在您的 Cloudflare KV 数据库中。只有在您通过后端 Worker 强鉴权登录后，真实数据才会被动态注入。请放心使用。

> [!CAUTION]
> **绝对不要在源码中硬编码密码！**
> 因为部署的前端页面资源对所有人可见，千万不要把任何个人密码、KV 凭证写在这个仓库的代码里。
