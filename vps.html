🔴 直连 VPS 节点 (DIRECT)
直连模式 不经过 Cloudflare network 网络，客户端通过域名 or IP 直接连接您的 VPS。
💡 适用场景：适用于自建 VPS 本身线路极佳（如 CN2 GIA、9929、CMIN2 优质网络），或者想本地直连测试、减少 CDN 中转延迟的场景。
🟡 小黄云 CDN 优选 VPS 节点 (CF_PROXY)
CDN 优选 客户端先连接 Cloudflare 的 Anycast 优选 IP，流量再通过 CDN 反向代理路由到您的自建 VPS。
💡 适用场景：适用于 VPS 本身直连网络较差，需要借助 Cloudflare 的 Anycast 优选 IP 优化网速，同时隐藏自建 VPS 真实 IP 防止被封的场景。
🔵 Argo 隧道优选 VPS 节点 (ARGO)
Argo 隧道 在 VPS 上启动 Cloudflare Argo 隧道，流量经由隧道直达 VPS 内部，无需在 VPS 开放任何公网端口。
💡 适用场景：适用于没有公网 IP（如家庭 NAS、内网局域网）或处于 NAT 网络限制下的 VPS，同时对防封锁和安全性要求极高的场景。
